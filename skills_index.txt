# Available Skills
You have access to domain knowledge skills about Roblox game development.
Use the `skill_view` tool to load a skill when you need specialized knowledge for the task.
Load skills proactively at the start if you can identify the domain from the task description.
You can load multiple skills and load more mid-conversation if you get stuck.
